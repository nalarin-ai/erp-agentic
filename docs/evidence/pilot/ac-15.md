# MVP-AC-15 — new unit + variable behavior without hardcode (UNIT-001, UX-001)

- Criteria: a new operating unit onboards purely through config/settings lifecycle — never via a unit-name source branch. Unknown/script settings, invalid references, unauthorized activation, version conflict, and rollback mismatch all fail closed; a source scan proves `src/` logic contains no per-unit-name branch.

## How the tests prove it

Suite: `tests/e2e/pilot/test_ac_15_no_hardcode.py` (11 tests; uses the real `UnitRegistry` / `UnitSettingsStore` and a synthetic `ZEPHYR_LABS` unit that exists only in the test).

1. **Config-only onboarding end-to-end:** `ZEPHYR_LABS` is added via `UnitRegistry.with_unit` (a `UnitSpec` data row), then driven through settings `draft → activate (CAS expected_version=0) → behavior resolves from ACTIVE settings → change via new draft+activate → rollback` — all without any source change. Full lifecycle is audited.
2. **Catalog row is data:** a valid synthetic catalog block parses through the strict minimal YAML parser (`_load_catalog_from_text`) with no code change.
3. **Unknown setting rejected:** a non-allowlisted key (`tax_profile_ref` — an FND-003 field, R-020) raises `InvalidDomainValue`.
4. **Script-like setting rejected:** `<script>…`, `javascript:…`, and a `;`-bearing ref all fail closed.
5. **Invalid reference rejected:** a template ref violating the opaque-ref grammar is rejected.
6. **Unauthorized activation rejected:** re-activating an ACTIVE version, or activating a bogus version, fails closed; drafting against an unregistered unit fails closed at the registry.
7. **expected_version conflict rejected (CAS):** a stale `expected_version` loses with a precise `version conflict`; the denial is audited and leaves zero rows.
8. **Rollback mismatch detected:** rollback CAS is evaluated BEFORE mutation — a stale `expected_version` is detected/rejected, no rollback row is appended, and active settings stay untouched.
9. **No unit-name source branch:** an AST-aware scan of `src/**/*.py` finds zero unit-name hits (`BANYUMEDIA|PR1ME|CONTRACTOR|HEAVY_EQUIPMENT|PT_TKH`) in executable code (docstrings/comments exempt).
10. **Catalog is the only unit source of truth:** the default registry resolves all six fixture units uniformly; the single-PPN-issuer invariant is a catalog property, not code.
