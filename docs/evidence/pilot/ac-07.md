# MVP-AC-07 — number/PDF only after post

- Criteria: a draft can never claim an official number; the official number and PDF reference exist only after a verified post.

## How the tests prove it

Suite: `tests/e2e/pilot/test_ac_07_number_after_post.py` (7 tests).

1. Draft snapshot exposes no `official_ref` / PDF reference.
2. Preview exposes no official number and shows the destination account only redacted (`ACC-[REDACTED]`).
3. `render_for_review` payload is a review artifact, not an official document (no official number/PDF fields).
4. Official number + `pdf_reference` appear ONLY on the `PostResult`/posted record after `post()` succeeds.
5. `get_posted_invoice` for an unposted reference → blocked/denied (no fabricated record).
6. Tampered preview (amount modified) → denied, zero provider writes.
7. Tampered preview hash → denied `PREVIEW_HASH_MISMATCH`, zero provider writes (`_verify_preview_authentic`).
